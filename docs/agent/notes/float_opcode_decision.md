# Opcode float

Новые коды — 28–37. Занятые коды не меняются. `script_vm/bytecode.mlc` этим шагом не правился.

Слово инструкции — одно `i32`: биты 0–7 opcode, 8–15 A, 16–23 B, 24–31 C (`instruction_encode` в `script_vm/bytecode.mlc`). Узкая форма, одно слово, как `instruction_words_binary`.

Занятые коды: 1–25 в `script_vm/bytecode.mlc`, 26 `LENGTH` и 27 `MAKE_STRING` в `script_vm/bytecode_text.mlc`. Коды 28–37 с ними не совпадают и помещаются в 8 бит opcode.

## Новые

| Имя | Код | A | B | C | Результат |
|---|---|---|---|---|---|
| FADD | 28 | приёмник | левый | правый | `ValueFloat64` |
| FSUB | 29 | приёмник | левый | правый | `ValueFloat64` |
| FMUL | 30 | приёмник | левый | правый | `ValueFloat64` |
| FDIV | 31 | приёмник | левый | правый | `ValueFloat64` |
| FCMP_EQ | 32 | приёмник | левый | правый | bool |
| FCMP_NE | 33 | приёмник | левый | правый | bool |
| FCMP_LT | 34 | приёмник | левый | правый | bool |
| FCMP_LE | 35 | приёмник | левый | правый | bool |
| FCMP_GT | 36 | приёмник | левый | правый | bool |
| FCMP_GE | 37 | приёмник | левый | правый | bool |

Оба операнда — регистры с `ValueFloat64`. Смешение с `i32` этими opcode не выполняется.

Коды 3–6 и 10–15 остаются прежними. `script_vm/arith.mlc` уже считает два float на ADD/SUB/MUL/DIV, а деление float на ноль там даёт `div_zero` (`char_arith`, метка `div_zero_float`). FDIV — другой код, opcode 6 не переписывается.

## Уже есть, новый код не нужен

| Операция | Имя | Код | Операнды |
|---|---|---|---|
| литерал | LOAD_CONST | 1 | A приёмник, B индекс константы; если индекс не влезает в 8 бит — B=0, C=1 и следом слово индекса. Константа — `ValueFloat64` |
| чтение поля | GET_PROP | 20 | A приёмник, B регистр записи, C индекс поля |
| запись поля | SET_PROP | 21 | A регистр записи, B индекс поля, C регистр значения |
| чтение элемента | GET_INDEX | 17 | A приёмник, B регистр массива, C регистр индекса |
| запись элемента | SET_INDEX | 18 | A регистр массива, B регистр индекса, C регистр значения |
| новый массив | NEW_ARRAY | 16 | A приёмник, B регистр длины |
| длина | LENGTH | 26 | A приёмник, B регистр массива, C 0 |

Значение слота не типизировано, отдельный opcode для float-поля и float-элемента не вводится. Условие `if`/`while` берёт bool из FCMP_* и существующий JUMP_IF_FALSE (код 9).
