Если карточка 361–374 всё же требует файл в `compiler/` или `lib/mlc/`, пропускаются только 361–374, ход продолжается с 375. Примечание шага 361 про остановку всей очереди не действует.
- Шаг 320. Число вне допуска записывается, шаг оптимизации не добавляется, очередь идёт дальше.
- Шаг 416, продолжать. Отдельная точка входа уже собирается существующим `mlcc` через `MLCC_ENTRY_BASENAME` (`tests_main`). `sandbox_main.mlc` — такая же точка входа.
