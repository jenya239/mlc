# Остаток после среза 201–300

Срез (Б) этой очереди закрыт: float в лоуэре, `match`, лямбды и замыкания из исходника, простые методы без generics и без наследования, имя поля в диагностике лоуэра.

## Остаток (Б)

- Generics в методах.
- Embedding: живая память REPL между вводами, fibers, дамп VM.
- Память производства: инкрементальный GC, лимит памяти элементов.

## (В)

- Quickening.
- Shapes.
- Inline caches.

Baseline JIT и tier-2 не входят ни в список (Б), ни в список (В) этой очереди.
